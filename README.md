Entry for the make.fun bounty **Fortune Cookie for the Liquidated Trader**. `main.ts` runs a small deterministic tournament over ten original fortune cookie lines, scoring each on the judge brief — fortune voice plus trading loss, a warm rueful laugh, one breath, a fresh turn, and the oracular voice broken by the punchline — and writes the winning line (97 characters, 18 words) to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The winning fortune: a cookie tells the freshly liquidated trader that riches are in their future — but the market saw them first and kept the change.

## Run it

```sh
node main.ts
```
